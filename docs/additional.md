# AndysLetter — 나중에 고려할 추가 기능

AndysLetter를 만들면서 떠올랐지만, 지금 단계에서는 만들지 않기로 한 아이디어들을
적어둔다. CLAUDE.md 4장(불필요한 추상화·미리 만드는 확장 금지) 원칙에 따라 실제로
필요해지기 전까지는 착수하지 않는다. 필요해지면 이 목록에서 항목을 골라 사용자에게
먼저 제안하고 승인받은 뒤 진행한다.

---

## 실시간 알림
새 편지가 도착하면 AndysLetter 탭에 뱃지를 띄운다. `supabase-js`는 realtime 구독을
이미 내장하고 있어서, CDN을 이미 로드해둔 지금은 채널 구독 코드 20줄 정도면 붙는다.
지금은 편지함을 열 때마다 새로 불러오는 것으로 충분하다.

## 답장 기능
받은 편지 상세 화면에서 "답장" 버튼 → 보낸이/받는이가 자동으로 뒤바뀐 채 편지 쓰기
창이 열린다. 3단계(편지 보내기·편지함) 완료 후 검토.

## 편지함 일괄 내보내기
편지함 전체를 한 번에 Drive/로컬로 옮기는 기능. 편지가 실제로 쌓이기 시작하면
검토한다. 지금은 한 통씩 내보내는 것으로 충분하다.

## 차단 목록
특정 우편번호에서 오는 편지를 거부. 스팸이 실제로 발생하면 추가한다.

## 지연 배송
`deliver_at` 컬럼 하나와 `letters` SELECT 정책에 `deliver_at <= now()` 조건만
추가하면 구현된다. 이번 라운드에서는 넣지 않기로 결정했다 (2026-08-08 결정 로그 참고).

## 편지지 커스텀 배경 이미지
지금은 편지지 8종을 순수 CSS로만 구현한다(이미지 없음). 나중에 사용자가 직접 사진을
편지지 배경으로 올리는 기능을 원하면, Drive의 별도 폴더에 이미지를 저장하고
`background-image`로 붙이는 방식을 검토할 수 있다.

## 관리자 다중 권한 레벨
지금은 `is_admin` boolean 하나뿐이라 관리자는 전부 동일한 권한(승인/거부 + 전체
유저 열람)을 가진다. 관리자가 여러 명이 되고 역할을 나눌 필요가 생기면
(예: 승인 권한만 있는 모더레이터) `role` 텍스트 컬럼으로 확장을 검토한다.

## 가입 승인 알림
지금은 관리자가 AndysLetter의 "관리자" 탭에 직접 들어가야 대기 중인 가입 신청을
본다. 신청이 잦아지면 이메일 알림(Supabase의 DB webhook → 이메일 서비스) 등을
검토할 수 있다.

## 우편번호 재발급/변경
지금은 최초 설정 이후 우편번호를 스스로 바꿀 수 없다(코드가 곧 신원이라 단순하게
유지). 필요해지면 관리자 승인을 거치는 변경 절차를 추가할 수 있다.
